# Изменения

## 1.0.0 — 2026-09-30

Первый выпуск.

### Возможности
- Окно «Из SQL (ER-диаграмма)…»: SQL вставкой, из файла или из базы PostgreSQL
  (через мост `npm start`, только чтение, пароль не сохраняется).
- PostgreSQL DDL; MySQL и SQLite распознаются автоматически.
- Таблицы — блоки со строками-колонками: ключи, ограничения как в SQL или короткими
  метками, NULL, индексы, комментарии (`COMMENT ON`, `--`, `COMMENT '…'`).
- ENUM и представления (`VIEW`, `MATERIALIZED VIEW`) — отдельные блоки со связями.
- Связи «воронья лапка» между строками, составные внешние ключи.
- Раскладка по столбцам с минимизацией пересечений, «окна» для длинных связей,
  ортогональная прокладка в обход таблиц; группы-рамки по схемам или префиксам;
  таблицы без связей — сеткой под схемой.
- Компактный режим: только ключи и связанные колонки.
- Выбор таблиц, «+ связанные».
- «Обновить на странице» — новая версия схемы с сохранением положения таблиц.
- «Перепроложить связи» после ручного перемещения таблиц.
- Подсветка связей выбранной таблицы.
- Экспорт диаграммы в SQL и Mermaid (erDiagram, в том числе для Markdown).
- Сравнение диаграммы со схемой в базе: отчёт и подсветка отличий.
- Легенда обозначений в окне плагина.
